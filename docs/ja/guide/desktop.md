# デスクトップのライブビューを開く

`default`イメージにはxfceデスクトップとChromiumが入っています。エージェントがスクリーンショットと入力で操作している様子を、ブラウザから見たり操作したりできます。

始める前に:

- [kumobaをインストールして`kumobad`を起動](/ja/getting-started)しておきます。
- ポート7789が空いていることを確認します。kumobadはこのポートでブラウザ用のリンクを提供します。

## ライブビューを開く

1. `default`イメージからサンドボックスを作って起動します:

   ```sh
   id=$(kumoba create --image default -q)
   kumoba start "$id"
   ```

2. デスクトップを起動し、ブラウザで開きます:

   ```sh
   kumoba desktop "$id" --user kumoba --open
   ```

   デスクトップが表示され、キーボードとマウスで操作できます。**Applications → Terminal Emulator**から、サンドボックス内のシェルを使えます。

リンクの有効期限は1時間です。期限が切れたら同じコマンドをもう一度実行してください。`--open`を付けない場合は、リンクが`url`として表示されます。

## ライブビューの動き

ライブビューはkumoba独自のビューアです。画面が変わったときだけブラウザに送るので、動きのないデスクトップでは通信量を使わず、CPUもほとんど使いません。

- **文字とウィンドウは正確に表示されます。** すべてのピクセルがデスクトップと一致します。スクロールやウィンドウのドラッグでは、新しく見えた部分だけを送ります。
- **動画やアニメーションは圧縮されます。** 再生中の動画のように変わり続ける領域は、なめらかさを保つために画質を下げて送ります。止まってから1秒ほどで、正確な表示に戻ります。
- **遅い回線では送る量を減らします。** ビューアが回線を測り、フレームレートを下げる前に、動いている領域の画質を下げます。
- **ポインタは操作している側に従います。** エージェントがポインタを動かしているときは、その動きが見えます。自分で動かしているときは、デスクトップのポインタの形が手元のポインタに表示されます。

バックグラウンドのタブには、戻ってくるまで何も送られません。

デスクトップのサイズが変わると、ライブビューも追従します。

## 入力、貼り付け、コピー

- **入力。** キーボードは入力した文字そのものを送るので、手元のキーボード配列に関係なく使えます。日本語などのIMEで変換した文字は、確定したときに送られます。サンドボックス側のキーボード配列にない文字は、最初の入力に少し時間がかかります。
- **貼り付け。** Ctrl+V（MacではCmd+V）を押します。手元のクリップボードのテキストがサンドボックスのクリップボードに入り、ライブビューが貼り付けを実行します。ターミナルにフォーカスがあるときは、ターミナル用の貼り付けショートカットを使います。
- **コピー。** MacではCmd+CまたはCmd+Xを押します。ライブビューが、フォーカスのあるアプリのコピー用ショートカットを送ります。それ以外の環境では、押したキーがそのままサンドボックスに届きます。多くのアプリではCtrl+C、ターミナルではCtrl+Shift+Cです。コピーしたテキストは手元のクリップボードに入ります。

テキストがサンドボックスの外に出るのは、ライブビューでコピーのショートカットを押してから2秒間だけです。ブラウザがページにクリップボードへの書き込みを許可している必要があり、それには`https`か`localhost`が必要です。

やり取りできるのはテキストだけで、上限は200,000バイトです。

## noVNCのビューアを使う

kumoba 0.4以前のイメージにはこのビューアが入っていないため、`kumoba desktop`はnoVNCを開きます。新しいイメージでnoVNCを使うには、次のように指定します:

```sh
kumoba desktop "$id" --user kumoba --viewer vnc --open
```

出力の`viewer`フィールドで、リンクがどちらを開くかがわかります。`stream`または`vnc`です。

## リモートマシンのライブビューを開く

kumobadがサーバーで動いている場合は、手元のPCからプレビュー用のポートを転送します:

```sh
ssh -N -L 7789:127.0.0.1:7789 my-server &
```

サーバーで`kumoba desktop <id> --user kumoba`を実行し、表示された`url`を手元のブラウザで開きます。
