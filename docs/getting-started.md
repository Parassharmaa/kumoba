# Getting started

::: warning Alpha
kumoba is alpha software. The HTTP API, the CLI, the SDK and the image format may change between releases, and guest images must be replaced when the protocol version changes. Pin a version (`KUMOBA_VERSION=0.2.2`) for anything you depend on.
:::
